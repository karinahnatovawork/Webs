# Imágenes esperadas

Coloca aquí tus fotos (JPG, idealmente ≥ 2000 px de ancho). Si falta alguna,
el sitio muestra un fondo crema en su lugar.

| Archivo            | Dónde se usa                                          |
| ------------------ | ----------------------------------------------------- |
| `cupula.jpg`       | Hero de la página de inicio y detalle en /espacios    |
| `ciudad-artes.jpg` | Hero de /espacios, habitación clásica, mosaico inicio |
| `lonja.jpg`        | Hero de /alrededores, habitación superior             |
| `mercado.jpg`      | Foto ancha de la página de inicio                     |
| `naranjas.jpg`     | Mosaico de inicio                                     |
| `azulejos.jpg`     | Mosaico de inicio                                     |
| `plaza-virgen.jpg` | Fondo de las bandas de llamada a la acción            |

Puedes renombrar los archivos; actualiza las rutas en `app/page.tsx`,
`app/espacios/page.tsx`, `app/alrededores/page.tsx` y `app/lib/content.ts`.
